# Harness Gap Audit — 10 Capability Dimensions

> **Date:** 2026-06-12 · **Method:** dynamic workflow (`harness-gap-audit`, run wf_d90e3725-e97) — 10 parallel evidence-grounded auditors, each claimed gap then adversarially re-verified by an independent skeptic instructed to refute it against the actual files. 20 agents, 436 tool uses.
> **Raw structured findings:** `verify/2026-06-12-harness-gap-audit/raw-audit.json`
> **Result:** 63 gaps survived verification (60 confirmed, 3 adjusted, **0 refuted** — every auditor claim held up against re-reading).

## Executive summary

The harness's recurring failure mode is the same one found in the 2026-06-12 memory-system review: **write paths, caps, and documentation exist; the consuming/enforcing half doesn't.** Across all ten dimensions the pattern repeats — telemetry captured but never read (cache tokens), pipelines built but with a dead middle stage (instincts, skill candidates), gates documented but wired to the wrong matcher or no matcher (pre-spawn-cost-gate), and verification that checks artifact *existence* rather than artifact *truth* (spec-match, evidence-gate, stop-verify).

### The three criticals

1. **Cross-learning (dim 5): instinct extraction never runs.** Observations accumulate in `observations.jsonl` (1,797 lines) but no hook, cron, or skill invocation ever spawns the Haiku extractor — `active.yml` doesn't exist. The entire continuous-learning loop is dead between capture and learning.
2. **ADR lifecycle (dim 7): zero real ADRs exist.** Nothing creates ADRs (no hook, no agent instruction that fires in practice), so staleness rules, conflict detection, re-verification, and "security disables require an ADR" all operate on an empty set. Enforcement is LLM-judged prose end to end.
3. **End-user verification (dim 9): `spec-match.sh` never checks the tagged test PASSED.** A failing Playwright journey still "proves" every AC it tags. Combined with agent-self-attested `evidence.json` that CI never re-runs, the 100%-AC-coverage guarantee is attestation, not verification.

### Cross-cutting themes (what to fix once, not ten times)

| Theme | Dimensions affected | Canonical fix |
|---|---|---|
| Telemetry captured, never consumed | 1 (cache tokens), 2 (context fill), 10 (revenue signal) | Every captured metric gets a reader: cost-report + statusline + doctor check |
| Pipeline with a dead middle stage | 3 (skill candidates), 5 (instinct extraction, global promotion), 6 (handoff→memory) | Wire stage N→N+1 with a cron/hook + doctor freshness check per stage |
| Gate exists, wired wrong or nowhere | 2 (pre-spawn-cost-gate on wrong matcher), 7 (ADR gates), 4 (disable-model-invocation) | settings.json matcher audit + validate.sh check that every gate has a registration |
| Existence-checked, truth-unchecked | 8 (stop-verify, trailers), 9 (spec-match pass status, evidence binding) | Gates assert on parsed verdicts/exit codes, not file presence |
| Advisory-only "auto" behaviors | 3/4 (router hints), 6 (delegation rules) | Either enforce mechanically or relabel as suggestions in docs — stop claiming "auto" |

### Priority order (impact ÷ effort)

1. `spec-match.sh` pass-status check + evidence↔PR binding (dim 9 critical+high) — small diffs, restores the core "done means proven" guarantee.
2. Wire `pre-spawn-cost-gate.sh` to the `Agent|Task` matcher (dim 2/6) — one settings line (operator).
3. Instinct extraction trigger: auto-dream-check or a Stop-hook counter spawns the Haiku extractor (dim 5 critical).
4. Cache hit-rate into cost-report + statusline + doctor (dim 1 high) — the data is already on disk.
5. ADR creation hook: architect/plan skill mandates an ADR file per plan; validate.sh fails a plan lacking one (dim 7).
6. Same-model review: route the `reviewer` agent to a different model than `implementer` in the routing table (dim 8 high — one frontmatter line + constitution row, operator).
7. Empty-backlog → ideation trigger in verify-loop/overnight (dim 10 high).
8. Skill-candidate consumer + dream-proposal isolation (dim 3 highs).
