New fixed factory-reporting-driver.py composes fresh fixed Python-I factory-git-state.py --config processes. There is no arbitrary command or source-path argument. The checkout HEAD and tracked script cleanliness are pinned/rechecked before each child; config bytes are pinned. Each child owns a fresh existing RoutedAPI invocation budget, never a reset within one invocation. Default job work budget720seconds, reserved30second cleanup window, maximum256invocations (validated hardmaximum512), and existing bounded-process child timeout ceiling300seconds. Deadline/iteration exhaustion returns incomplete and leaves protected state to the next job; it is not acceptance of a partial or late report.

Only successful incomplete children continue. Delivery/not-due stop; nonzero child, malformed/uncertain/unsupported result, source changes and observer/provider errors stop without tight retries. No child diagnostic bodies or credentials are logged in App-on mode. A separate actual routed read-only observer checks the exact same-repository state branch head after incomplete work, preserving one transport budget for the whole job; three consecutive unchanged transitions stop spinning.
