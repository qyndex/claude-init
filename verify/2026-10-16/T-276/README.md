Only T-276 is implemented here. Source policy and all six emitter closure files are fetched at that SHA as bounded bytes; canonical policy hash must select one active approved profile, followed by exact runtime hashes. Profile mismatch never falls back to available legacy revision pins. Existing callers retain reviewed exact-revision legacy compatibility; external legacy mode is explicitly selected. Empty shipped profile remains inactive. No hosted callers, flags, pins or authority settings changed.
