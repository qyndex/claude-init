# Neutral reusable factory distribution

Authorized F-07 prerequisite: adopted repositories must receive the pinned dependencies and neutral configuration references needed by installed factory scripts. Preserve immutable transactional ownership; no external activation or dependency execution during installation.

## Acceptance criteria

1. **AC-1**: Explicitly package the pinned feedback encryption requirements, disabled neutral configuration examples and relevant runtime/reporting/feedback guides from clean immutable tracked source. New and existing adopter fixtures retain their own content and receive complete owned files.
2. **AC-2**: Exclude source pilot policy, GitHub App identity, live workflows, operator/channel IDs, private state and credentials. Disabled examples contain no source repository defaults; missing per-adopter values cannot imply enabled authority.
3. **AC-3**: Replay and clean upgrades preserve version/hash/mode ownership, reject customized dependency/example collisions before partial changes and support guarded revert. Existing transactional adoption contracts remain passing.
4. **AC-4**: Installing the package performs no pip/network/provider invocation or target setup. Guides provide explicit pinned isolated dependency provisioning outside candidate state and explain independent per-repository activation, runtime image/credential boundaries and unproven native subscription/deployment gates.
